# Historial de las skills clínicas

Este repositorio versiona las skills clínicas y su interfaz. Las demás skills quedan fuera del alcance.

- Conservar un commit por cambio coherente, después de revisar el diff y completar las comprobaciones pertinentes. Respetar cualquier petición del usuario de no crear commits.
- `.gitignore` enumera los archivos revisados. Añadir allí los nuevos archivos de código, pruebas, instrucciones o plantillas vacías que correspondan. No usar `git add -f` para eludir esa revisión.
- No versionar expedientes, descargas, colas, sesiones, contraseñas ni tokens. Los datos clínicos permanecen fuera del repositorio.
- No publicar ni configurar remotos sin solicitud del usuario. Git local conserva historial; no reemplaza una copia externa.
- Antes de cambiar autenticación o descargas, leer la skill afectada. Para la interfaz, conservar fuentes independientes, períodos por fuente, entrega opcional y fechas DD-MM-AAAA.
